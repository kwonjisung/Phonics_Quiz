# Phonics Quiz 단어 카드

6살 아이 파닉스 받아쓰기 시험 단어를 하루 3개씩, 움직이는 그림 카드로 보여주는 웹앱입니다.

- 위쪽에서 시험 날짜를 바꾸면 그날 단어 3개가 나옵니다.
- 단어 글자는 그대로 두고, 그림은 글자 밖에서만 움직입니다.
- 같은 소리 규칙(-ot, a_e, i_e, o_e)은 주황색으로 표시합니다.
- 단어·문장·천천히 듣기 버튼으로 발음을 들을 수 있습니다.

새 달 단어를 넣으려면 `index.html`의 `DAYS` 목록에 날짜와 단어를 추가하고, `SCENES`에 단어별 장면을 넣으면 됩니다.
